SYSTEM ARCHITECTURE

The Multi-Modal Verification Pipeline

How TrustLens fuses deep convolutional neural networks with semantic optical character recognition to detect sophisticated digital payment forgeries.

STAGE 01

MobileNetV2 CNN

Extracts 1,280 spatial deep visual features. Evaluates micro-texture inconsistencies, font rendering distortions, and compression noise signatures across the receipt canvas.

STAGE 02

EasyOCR Engine

Performs text detection and recognition to parse essential transaction entities: UPI VPA syntax, Bank Reference IDs, transaction amounts, timestamps, and recipient metadata.

STAGE 03

Multimodal Fusion

Concatenates the 1,280 visual embedding vector with 5 lexical/syntactic features (text density, UPI structure, txn pattern, amount count, date count) into a unified 1,285-d vector.

STAGE 04

XGBoost Classifier

Gradient-boosted decision trees analyze feature interactions to compute classification probabilities, determining if the receipt is Real or Fake with a calibrated Trust Score.

STAGE 05

SHAP & Forensic PDF

Computes Shapley additive explanations (SHAP) to provide transparent feature attribution, renders an anomaly heatmap, and compiles an automated, court-ready PDF forensic report.

Common UPI Forgery Attacks Detected

Synthetic payment receipts generated by scam applications, fake receipt generators, or manual image manipulation exhibit subtle structural anomalies that TrustLens isolates.

Font & Kerning Tampering

Counterfeit generators often use incorrect font weights, improper letter-spacing, or mismatched glyphs when substituting merchant names and payment amounts.

Invalid UPI VPA Formatting

Genuine transactions follow standard NPCI handle conventions (`name@bank`). Forged receipts frequently incorporate invalid banking handles or syntactically broken identifiers.

Spoofed Transaction IDs

Transaction identifiers adhere to length, date-code prefixes, and algorithmic check sequences. TrustLens identifies randomized or out-of-sequence reference numbers.

Splicing & Compression Noise

When text is pasted over a background, Error Level Analysis (ELA) and MobileNetV2 detect localized compression variance and unnatural gradient seams invisible to the naked eye.
